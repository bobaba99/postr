Read this as a shape, not a forecast. Postr is not subscription SaaS — it's a one-time term unlock closer to occasion-driven e-commerce, so every benchmark here is a directional analog from an adjacent market, not a measurement of this product. The value is in the relationships — how balance responds to conversion, repurchase, and the summer trough — not in any single dollar figure. The first real conversion event will beat all of it.
