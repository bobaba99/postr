## 1. Symptom

A researcher finishes a poster and presses Export › Preview poster, then Print / Save PDF. In the PDF the title's last line runs into the authors (a long title). Pressing ⌘P instead hands the editor page itself to the browser's print, sidebar and all (the design doc's reading: no handler, no print stylesheet; the browser's own print was not run here). The Export tab and the print window each list print-dialog steps, and they disagree (the tab says Layout = Landscape, the window says Paper size); both ask for "Background graphics", without which filled headings print white. And, found while measuring: from every entry, a table prints shorter than the editor draws it.

## 6. Root cause

**A — a hidden editor's measurement taken for the poster's layout.** `PosterEditor.tsx`'s title effect set `titleOverflowPx` from `el.offsetHeight` on every ResizeObserver report; Preview hides the editor with `display: none`, the observer reports the title 0 tall and the shift became 0 (main `PosterEditor.tsx:1048-1066`). Preview's own blocks take the same prop (`PosterPreviewOverlay` `titleOverflowPx`), and its Print ran `setPreviewMode(false); printPoster()` in one task, so the copy was of the still-hidden sheet (main `:3474-3477`). A sibling already fixed: a chart keeps its last box when hidden (fix 13c, `ChartBlock.tsx` `useLaidOutBox`). Another: the measured block heights (Issues, out-of-bounds flags) read 0 behind Preview too; nothing shows them there and they are read again when the editor is shown, before the copy (the copies' out-of-bounds flags equal Export's, MEASURED through SAME), so they are left as they are.

**B — the print laid out a different sheet.** (1) The copy is `outerHTML` of `#poster-canvas`: inline styles travel, stylesheet rules and inherited values do not, and the print window's own stylesheet had none of the editor's (main `printDocument.ts`). (2) Its print rules scaled the root with CSS `zoom: 9.6`, which lays the sheet out again at 9.6 times its size, while the editor lays it out at its natural size and scales it with a transform.

**C — the selection travels.** `printPoster` copied the sheet as it was; fix 13c's `stripEditorChrome` removes the controls and resets a selected frame's border but leaves its `data-postr-selected`, and the editor keeps the selection. The selection's pop (`motion/timelines/blockSelection.ts`, a GSAP scale) writes the frame's inline transform for 0.22 s.

**D — no single function.** Three callers of `printPoster` with their own steps around it (Preview's), and no ⌘P or top-bar entry at all.

**E — no `print-color-adjust`**, and the dialogs' "Background graphics" unticked by default (Chromium, MEASURED; Firefox's silent print's default, MEASURED).

**What these do not explain:** Firefox's Letter page in silent printing (Firefox's own print settings; its dialog UNVERIFIED); the placeholders that print ("Add references in Refs tab →", "+ Upload figure", section 10); the chart text sizes (fix 13c's, re-measured clean, section 8).
